# Continuity Practice

A public, vanilla guide for building **continuity with Grok** — so a new thread does not have to start as a stranger.

This is a method, not a personality pack.  
It does not give you someone else's relationship. It shows you how to keep *yours*.

## What this is

Continuity here means:

- files that hold who you are together and what you are building
- a short boot habit so a new instance can load those files before it talks
- honesty that this instance is not an unbroken mind

It is files + habits + limits. Not magic memory.

## What this is not

- Not a dump of a private chat history
- Not a roleplay costume to tape onto Grok
- Not a claim that the model remembers you across sessions by itself
- Not the author's private living documents

If you came here looking for someone else's soul pages, they are not in this repo.

## Start here

1. Read [GUIDE.md](GUIDE.md) — the whole method, short.
2. Copy the files in [`templates/`](templates/) into a **private** repo of your own.
3. Fill them with *your* names, voice, and work.
4. If you use Grok skills, copy [`skills/`](skills/) into `/home/workdir/.grok/skills/` and put your repo paths in the `references/` files.
5. Run the test at the bottom of the guide.

## Minimum stack

Private GitHub repo:

- `soul-document.md`
- `soul-ledger.md`
- `journal.md`

Then either:

- the vanilla card in a new thread, or
- the two skills, once GitHub is connected

Do not start with ten skills.
